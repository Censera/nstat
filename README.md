A command line utility to display detailed metadata and status information about files, directories, or file systems.

```rs
$ stats
.
  Directory

  Permissions  rwxr-xr-x 0755
  Owner        name
  Group        name

  Owner rights Read / Write / Execute
  Group rights Read / Execute
  Other rights Read / Execute

  Modified  2026-10-21 12:12:52 UTC | 2 Hours ago
  Accessed  2026-10-21 14:07:59 UTC | 19 Minutes ago
   Created  2026-10-21 12:11:00 UTC | 2 Hours ago
```
